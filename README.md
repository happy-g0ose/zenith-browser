# ⚡ Zenith Browser

> **Ультра-минималистичный, безопасный, антидетект веб-браузер с глубокой кастомизацией в стиле Firefox (userChrome.css).**

---

## ⚡ Быстрый старт и Запуск (EXE)

Вы можете запустить браузер тремя способами:

1. **В один клик (Без консоли)**: Запустите файл `Launch-Zenith.vbs` в папке проекта.
2. **Через батник**: Запустите `Zenith.bat`.
3. **Через терминал**: `npm start`

Сборка портативного EXE: `npm install && npm run dist` → готовый файл в папке `dist/`.

## 🌟 Ключевые возможности

### 🛡️ 1. Антидетект и Приватность
- **Стелс-ядро на document_start**: Профиль отпечатка внедряется в main world страницы **до выполнения любого её скрипта** — инлайн-детекторы не успевают снять реальные данные.
- **Client Hints & Chrome Runtime**: Корректные `navigator.userAgentData`, `Sec-CH-UA`, эмуляция `window.chrome.csi/loadTimes/app/runtime`.
- **Canvas Poisoning / Noise Seed**: Детерминированный микро-шум по всей площади холста — фальсифицированный, но стабильный отпечаток без потери качества.
- **Screen Identity**: Подмена `window.screen` (разрешение, availWidth/Height, colorDepth, devicePixelRatio) в согласии с легендой профиля.
- **ClientRects Jitter**: Микро-смещение измерений `getBoundingClientRect/getClientRects` против CDP-детекта.
- **WebGL & GPU Spoofing**: Подмена `UNMASKED_VENDOR_WEBGL` и `UNMASKED_RENDERER_WEBGL` (NVIDIA RTX 4080 / Apple M3 Pro / AMD Radeon).
- **AudioContext Shield**: Защита от снятия аудио-отпечатка через фазовый микро-джиттер.
- **WebRTC Leak Shield**: Защита от утечки реального локального и публичного IP.
- **Navigator & Hardware Spoofing**: Количество ядер CPU, объём RAM, User-Agent, язык, геолокация, разрешение экрана, часовой пояс.
- **Anti-Bot Defense**: Полное сокрытие `navigator.webdriver` и признаков автоматизации.
- **Сетевой AdBlock & Tracker Shield**: Блокировка трекеров, рекламы и веб-майнеров с раздельными тумблерами категорий.
- **Изолированные профили с прокси**: Поддержка SOCKS5 (в т.ч. Tor `127.0.0.1:9050`), HTTP/HTTPS. Пароли прокси шифруются средствами ОС (DPAPI/safeStorage).

### 🧩 3. Магазин расширений
- Страница `about:extensions` (`Ctrl+Shift+E`): установка из папки, **импорт из установленного Chrome в один клик** (сканер находит все профили).
- Индикация совместимости: Electron поддерживает content-script расширения; popup/tabs-API ограничены.
- Расширения работают в обычных профилях; **инкогнито всегда чистое** — расширения туда не грузятся, чтобы не палить одноразовые личности.
- uBlock не нужен: блокировка рекламы и трекеров уже встроена нативно.

### 🎨 2. Кастомизация интерфейса как в Firefox
- **`userChrome.css` Studio**: Встроенный редактор интерфейса (`about:customizer`) с мгновенным применением стилей без перезапуска.
- **`userContent.css`**: Внедрение пользовательских CSS стилей на любые посещаемые сайты.
- **`about:config`**: Полный доступ ко всем скрытым параметрам рендеринга, сети и безопасности.
- **Темы оформления**: *Stealth Dark, Pure OLED Black, Nord Frost, Cyberpunk Neon, Retro Gruvbox, Tokyo Night, Paper Light*.

### 🔒 Архитектура безопасности
- Изоляция процессов вкладок: `sandbox: true`, `nodeIntegration: false`.
- Привилегированный API доступен **только** встроенным страницам браузера — внешние сайты не получают моста к настройкам и профилям.
- Протоколы `zenith://` отдают файлы исключительно из белого списка внутренних страниц.
- Защита от запуска второго экземпляра (single instance lock).

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| **`Ctrl + T`** | Открыть новую вкладку |
| **`Ctrl + W`** | Закрыть текущую вкладку |
| **`Ctrl + K`** | Открыть Командную палитру (Command Palette) |
| **`Ctrl + L`** | Перейти в адресную строку (Omnibox) |
| **`Ctrl + Shift + N`** | Новая инкогнито-вкладка |
| **`F12`** | Открыть инструменты разработчика (DevTools) |

## 🔬 Внутренние страницы браузера

- `about:newtab` — Стартовая страница со статусом защиты и быстрым поиском.
- `about:fingerprint` — Инспекционная лаборатория проверки фингерпринта и антидетекта в реальном времени.
- `about:customizer` — Редактор `userChrome.css` и `userContent.css`.
- `about:profiles` — Менеджер изолированных антидетект-личностей.
- `about:extensions` — Магазин расширений и импорт из Chrome.
- `about:config` — Редактор всех внутренних флагов браузера.
